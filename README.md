> **"Moving in the rhythm now."**
> 
> 인디 게임 개발자 Bernie Wick([@partnano](https://www.threads.com/@partnano))의 Threads 포스트 *"Slowly a game"* 속 레트로 2D 픽셀 아트 리듬 어드벤처 게임을 웹 기반으로 1:1 완벽 구현한 프로젝트입니다.

🔗 **라이브 데모 (GitHub Pages)**: [https://jeiel85.github.io/lyra-cadence-rhythm-game/](https://jeiel85.github.io/lyra-cadence-rhythm-game/)

## 🎮 게임 개요

레트로 콘솔(GBC / 16-bit RPG) 감성의 탑다운 픽셀 아트 어드벤처에 **리듬 동기화(Rhythm Beat Sync)** 메커니즘이 결합된 게임입니다.  
배경 음악의 박자(BPM)에 맞춰 걷거나 공격하면 **콤보(Combo)**가 쌓이고 리듬 파워가 충전되며, 스테이지의 기믹과 퍼즐을 해결하여 최종 보스 **Cadence Overlord**를 격퇴해야 합니다.

## 🕹️ 조작 방법

### PC 키보드
* **이동**: 방향키 (`▲` `▼` `◀` `▶`) 또는 `W` `A` `S` `D`
* **공격 / 상호작용**: `Space` 또는 `Z`
* **대화 넘기기**: `Enter` 또는 `Space`
* **스테이지 재시작**: `R`
* **음소거 토글**: `M`

### 모바일 / 태블릿 터치
* 화면 하단 전용 레트로 **가상 D-패드** 및 **A / B 버튼** 지원
* 하단 바의 `📱 Touch Pad` 버튼으로 언제든 가상 패드를 켜고 끌 수 있습니다.

## 🗺️ 스테이지 구성

1. **Stage 1: Riverside Meadow (강변 초원 - 원작 도입부 재현)**
   * 원작 영상의 구도를 그대로 재현: 절벽, 목재 울타리, 강변과 나룻배 다리, 음표(♪) 타일.
   * 튜토리얼: 리듬에 맞춰 걸으며 조작을 익히고, 박자에 맞춰 음표 발판을 밟아 나무통 다리를 연결해 강을 건넙니다.
2. **Stage 2: Whispering Woods (속삭이는 숲)**
   * 박자에 맞춰 튀어오르는 슬라임과 박자 박쥐 몬스터 등장.
   * 비트에 맞춰 솟구치는 리듬 가시 함정 회피.
   * 3개의 화음 룬 크리스탈을 모아 닫힌 숲의 관문을 엽니다.
3. **Stage 3: Echo Ruins (공명의 사원)**
   * 130 BPM의 빠른 템포로 전환!
   * 4개의 넘버링 리듬 패드(1-2-3-4)를 박자를 놓치지 않고 연속으로 밟아 결계를 해제하는 리듬 퍼즐.
4. **Stage 4: The Maestro's Core (최종 보스전: Cadence Overlord)**
   * **Phase 1**: 보스의 열/행 충격파 패턴 회피 및 보스가 발사하는 공명 구체를 타이밍에 맞춰 검으로 패링(반사)하여 보스의 실드를 파괴!
   * **Phase 2 (광폭화)**: 보스가 중심부로 강림하며 나선형 리듬 탄막을 전방위로 방출! 코어가 직접 노출되며, 비트에 맞춘 근접 연속 공격으로 보스를 쓰러뜨립니다.
   * 클리어 시 최종 스코어, 최대 콤보, 박자 정확도 및 랭크(S / A / B / C)가 표시됩니다.

## 🛠️ 기술적 특징

* **Web Audio API Chiptune 엔진**: 외부 MP3 파일 다운로드 없이 브라우저 내장 오디오 신시사이저로 8-bit / 16-bit 칩튠 BGM과 효과음을 실시간 합성합니다. 오디오 지연(Latency)이 0에 수렴하여 완벽한 박자 동기화를 제공합니다.
* **절차적 픽셀 아트 렌더러**: 외부 이미지 다운로드 실패 위험 없이 Canvas API를 통해 원작 스크린샷의 색감과 캐릭터(Lyra), 타일, 보스를 정밀 렌더링합니다.
* **CRT 레트로 스캔라인 & 셰이더 필터**: 레트로 브라운관 모니터 특유의 주사선 및 비네트 효과를 토글할 수 있습니다.
